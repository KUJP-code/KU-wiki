## MVP 1

### Admin panel

- Create, edit, delete courses
- Create and order weeks within a course
- Weekly intro/background image
- Vocabulary icons with voice clips: tap to hear English
- Target phrases
- Basic English: main video, timestamps, iPad teacher guide
- Activity Time: multiple videos (3?), timestamps, iPad guide, worksheet and teacher prep PDFs
- Add Vimeo links, chapter timestamps, lesson titles and guides
- Upload activity materials
- Preview before publishing

### Revisions

- Lesson types attach to a week in a course
- Story Time is a shared library/list, rotated as new content comes in
- Vocabulary tray for MVP; potentially clickable areas in the background later
- Maybe the same library setup for songs later. **Not MVP**

### Teacher UI

- Login
- Show course assigned to the teacher's organisation
- Automatically show current week based on the plan
- Previous/next week navigation
- DB notes put plans on schools; MVP notes say organisation. Still to decide

### Week / lesson view

- Weekly background, target phrases (maybe in the image?)
- Basic English
- Activity Time: multiple videos, 3 planned
- Story Time selector: stories available at any time
- Video/content buttons in a consistent menu area over the background
- Vocabulary tray: large image cards, tap for audio, easy to dismiss
- View PDF materials

### Video player

- Start video from the lesson menu → full screen on TV from mirroring mode
- Overlay remote control, teacher guide on screen too
- Play/pause
- Skip forward/back 5s
- Change playback speed
- Large tablet-friendly controls
- Chapter skip forward/back

## Feedback / maybe later

- Pause at chapter ends and prompt teacher to wait for output
- Chapters are manually added timestamps
- Check if the app can follow the current chapter and change the teacher guide
- Combine chapter guides into a downloadable lesson guide
